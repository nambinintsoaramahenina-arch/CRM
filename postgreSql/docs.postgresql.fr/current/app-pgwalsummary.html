pg_walsummary

pg_walsummary — Afficher le contenu des fichiers résumés de WAL

Synopsis

pg_walsummary [option...] [fichier...]

Description

pg_walsummary est utilisé pour afficher le contenu des fichiers de résumé de WAL. Ces fichiers binaires sont placés dans le sous-répertoire pg_wal/summaries du répertoire principal des données, et peuvent être convertis en texte en utilisant cet outil. Ce n'est pas fréquemment utile car les fichiers de résumé de WAL existent principalement pour la sauvegarde incrémentale, mais cela pourrait être utile pour du débugage.

Un fichier de résumé de WAL est indexé par l'OID du tablespace, l'OID de la relation et le type de relation. Pour chaque type, il enregistre la liste des blocs qui ont été modifiés dans l'intervalle résumé de ce fichier. Il peut aussi enregistrer une limite de bloc, qui vaut 0 si le fichier de ce type de relation a été créé ou tronqué dans l'intervalle adéquat de WAL. Sinon il vaut la longueur la plus courte à laquelle le fichier de ce type de relation a été tronqué. Si le fichier de ce type de relation n'a pas été créé, supprime ou tronqué dans l'intervalle adéquat de WAL, le bloc limite est indéfini ou infini, et ne sera pas affiché par cet outil.

Options

-i
--individual

Par défaut, pg_walsummary affiche une ligne de sortie pour chaque intervalle de un ou plusieurs blocs consécutifs modifiés. Ceci peut rendre la sortie bien plus courte car une relation où tous les blocs de 0 à 999 ont été modifiés produira une ligne en sortie, plutôt que 1000 lignes séparées. Cette option réclame une ligne séparée de sortie pour chaque bloc modifié.

-q
--quiet

N'affiche rien en sortie, sauf en cas d'erreurs. Ceci peut être utile quand vous avez besoin de savoir si un fichier résumé de WAL peut être analysé avec succès, mais que vous n'avez aucun intérêt dans son contenu.

-V
--version

Affiche la version, puis quitte.

-?
--help

Affiche l'aide sur les arguments en ligne de commande de pg_walsummary, puis quitte.

Environnement

La variable d'environnement PG_COLOR indique s'il faut utiliser, ou non, la couleur pour les messages de diagnostic. Les valeurs acceptées sont always, auto et never.
