H.1. Interfaces client #

Il n'existe que deux interfaces clients dans la distribution de base de PostgreSQL :

  • libpq, car il s'agit de l'interface principale pour le langage C et parce que de nombreuses interfaces clients sont construites par dessus ;

  • ECPG, car il dépend de la grammaire SQL côté serveur et est donc sensible aux modifications internes de PostgreSQL.

Tous les autres interfaces sont des projets externes et sont distribués séparément. Une liste des interfaces est maintenue sur le wiki PostgreSQL. Notez que certains de ces packages ne sont pas disponibles sous la même licence que PostgreSQL. Pour plus d'informations sur chaque interface, avec les termes de la licence, référez-vous à son site web et à sa documentation.
