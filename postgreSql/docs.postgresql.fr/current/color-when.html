N.1. Quand les couleurs sont utilisées #

Pour utiliser la sortie colorée, affecter la variable d’environnement PG_COLOR comme suit :

  1. Si la valeur est always, alors les couleurs sont utilisées.

  2. Si la valeur est auto et que le flux de sortie standard d'erreur est associé à un périphérique terminal, alors la couleur est utilisée.

  3. Autrement, la couleur n'est pas utilisée.
