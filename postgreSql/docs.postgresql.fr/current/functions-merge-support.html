9.23. Fonctions de support pour la commande Merge #

PostgreSQL inclut une fonction de support pour la commande merge qui peut être utilisée dans une liste RETURNING d'une commande MERGE pour identifier l'action à prendre pour chaque ligne : voir Tableau 9.66.

Tableau 9.66. Fonctions de support de merge

Fonction

Description

merge_action ( ) → text

Renvoie la commande d'action du merge à exécuter pour la ligne courante. Les valeurs possibles sont 'INSERT', 'UPDATE' ou 'DELETE'.


Exemple : 

MERGE INTO products p
  USING stock s ON p.product_id = s.product_id
  WHEN MATCHED AND s.quantity > 0 THEN
    UPDATE SET in_stock = true, quantity = s.quantity
  WHEN MATCHED THEN
    UPDATE SET in_stock = false, quantity = 0
  WHEN NOT MATCHED THEN
    INSERT (product_id, in_stock, quantity)
      VALUES (s.product_id, true, s.quantity)
  RETURNING merge_action(), p.*;

 merge_action | product_id | in_stock | quantity
--------------+------------+----------+----------
 UPDATE       |       1001 | t        |       50
 UPDATE       |       1002 | f        |        0
 INSERT       |       1003 | t        |       10

Notez que cette fonction peut seulement être utilisée dans la liste RETURNING d'une commande MERGE. L'utiliser dans toute autre partie d'une requête renverra une erreur.
