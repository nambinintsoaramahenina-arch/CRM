51.14. pg_conversion #

Le catalogue pg_conversion décrit les fonctions de conversion de codage. Voir la commande CREATE CONVERSION pour plus d'informations.

Tableau 51.14. Colonnes de pg_conversion

Type

Description

oid oid

Identifiant de ligne

conname name

Nom de la conversion (unique au sein d'un namespace)

connamespace oid (référence pg_namespace.oid)

OID du namespace qui contient la conversion.

conowner oid (référence pg_authid.oid)

Propriétaire de la conversion

conforencoding int4

Identifiant de l'encodage source (pg_encoding_to_char() peut traduire ce nombre par le nom de l'encodage)

contoencoding int4

Identifiant de l'encodage de destination (pg_encoding_to_char() peut traduire ce nombre par le nom de l'encodage)

conproc regproc (référence pg_proc.oid)

Procédure de conversion

condefault bool

Vrai s'il s'agit de la conversion par défaut
