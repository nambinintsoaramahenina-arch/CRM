35.22. domain_udt_usage #

La vue domain_udt_usage identifie tous les domaines utilisant les types de données possédés par un rôle actif. Sous PostgreSQL, les types de données internes se comportent comme des types utilisateur. Ils sont donc inclus ici.

Tableau 35.20. Colonnes de domain_udt_usage

Type de la colonne

Description

udt_catalog sql_identifier

Nom de la base de données de définition du type de données domaine (toujours la base de données courante)

udt_schema sql_identifier

Nom du schéma de définition du type de données domaine

udt_name sql_identifier

Nom du type de données domaine

domain_catalog sql_identifier

Nom de la base de données contenant le domaine (toujours la base de données courante)

domain_schema sql_identifier

Nom du schéma contenant le domaine

domain_name sql_identifier

Nom du domaine
