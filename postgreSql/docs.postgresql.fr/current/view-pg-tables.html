52.30. pg_tables #

La vue pg_tables fournit un accès aux informations utiles de chaque table de la base de données.

Tableau 52.30. Colonnes de pg_tables

Type

Description

schemaname name (référence pg_namespace.nspname)

Nom du schéma qui possède la table

tablename name (référence pg_class.relname)

Nom de la table

tableowner name (référence pg_authid.rolname)

Nom du propriétaire de la table

tablespace name (référence pg_tablespace.spcname)

Nom du tablespace qui contient la table (NULL s'il s'agit du tablespace par défaut de la base)

hasindexes bool (référence pg_class.relhasindex)

Vrai si la table comporte (ou a récemment comporté) des index

hasrules bool (référence pg_class.relhasrules)

Vrai si la table dispose (ou disposait) de règles

hastriggers bool (référence pg_class.relhastriggers)

Vrai si la table dispose (ou disposait) de déclencheurs

rowsecurity bool (référence pg_class.relrowsecurity)

Vrai si la sécurité niveau ligne est activée sur la table
