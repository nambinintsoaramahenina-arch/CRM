35.12. column_column_usage #

La vue column_column_usage identifie toutes les colonnes générées qui dépendant d'une autre colonne de base dans la même table. Seuls les tables possédées par le rôle actuel sont incluses.

Tableau 35.10. Colonnes de column_column_usage

Type de la colonne

Description

table_catalog sql_identifier

Nom de la base contenant la table (toujours la base actuelle)

table_schema sql_identifier

Nom du schéma contenant la table

table_name sql_identifier

Nom de la table

column_name sql_identifier

Nom de la colonne de base dont la colonne générée dépend

dependent_column sql_identifier

Nom de la colonne générée
