O.2. Les rôles par défaut sont renommés en rôles prédéfinis #

PostgreSQL 13 et les versions précédentes utilisent le terme « rôle par défaut ». Cependant, comme ces rôles ne peuvent pas être changés et sont installés comme faisant partie du système à l'initialisation, le terme le plus approprié à utiliser est « rôles prédéfinis ». Voir Section 21.5 pour la documentation actuelle à propos des rôles prédéfinis, et les notes de version pour PostgreSQL 14 pour plus de détails sur ce changement.
