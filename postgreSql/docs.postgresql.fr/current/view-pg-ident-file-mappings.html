52.10. pg_ident_file_mappings #

La vue pg_ident_file_mappings fournit un résumé du contenu du fichier de configuration des correspondances des noms d'utilisateur, pg_ident.conf. Une ligne apparaît dans cette vue pour chaque ligne du fichier qui n'est ni vide ni un commentaire, avec des annotations indiquant si la carte peut être appliquée avec succès.

Cette vue peut être utile pour vérifier si les modifications prévues dans le fichier de configuration des authentifications fonctionneront ou pour diagnostique un échec précédent. Notez que cette vue donne des informations sur le contenu actuel du fichier, et non pas sur ce qui a été chargé en dernier par le serveur.

Par défaut, la vue pg_ident_file_mappings peut seulement être lue par les superutilisateurs.

Tableau 52.10. Colonnes de pg_ident_file_mappings

Type

Description

map_number int4

Numéro de cette carte, par ordre de priorité, si valide, sinon NULL

file_name text

Nom du fichier contenant cette carte

line_number int4

Numéro de ligne de cette carte dans file_name

map_name text

Nom de la carte

sys_name text

Nom d'utilisateur détectée du client

pg_username text

Nom d'utilisateur PostgreSQL démandé

error text

Si non NULL, message d'erreur indiquant pourquoi cette ligne n'a pas été traitée


Habituellement, une ligne reflétant un enregistrement incorrect aura des valeurs uniquement pour les champs line_number et error.

Voir Chapitre 20 pour plus d'informations sur la configuration de l'authentification des clients.
