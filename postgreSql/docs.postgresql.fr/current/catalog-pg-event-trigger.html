51.21. pg_event_trigger #

Le catalogue pg_event_trigger enregistre les triggers sur événement. Voir Chapitre 38 pour plus d'informations.

Tableau 51.21. Colonnes de pg_event_trigger

Type

Description

oid oid

Identifiant de ligne

evtname name

Nom du trigger (doit être unique)

evtevent name

Identifie l'événement pour lequel ce trigger se déclenche

evtowner oid (référence pg_authid.oid)

Propriétaire du trigger d'événement

evtfoid oid (référence pg_proc.oid)

La fonction à appeler

evtenabled char

Contrôle le mode session_replication_role dans lequel ce trigger d'événement se déclenche. O = le trigger se déclenche dans les modes « origin » et « local », D = le trigger est désactivé, R = le trigger se déclenche dans le mode « replica », A = le trigger se déclenche toujours.

evttags text[]

Balises de commande pour lesquelles ce trigger va se déclencher. Si NULL, le déclenchement de ce trigger n'est pas restreint sur la base de la balise de commande.
