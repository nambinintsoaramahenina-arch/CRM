52.5. pg_config #

La vue pg_config décrit les paramètres de configuration au moment de la compilation, pour la version actuellement installée de PostgreSQL. Elle a pour but d'être utilisé par les paquets logiciels souhaitant une interface vers PostgreSQL pour faciliter la recherche des fichiers d'en-tête et bibliothèques. Elle fournit les mêmes informations basiques que l'outil client pg_config de PostgreSQL.

Par défaut, la vue pg_config peut seulement être lue par des superutilisateurs.
