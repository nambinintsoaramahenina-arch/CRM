J.4. Construire la documentation avec Meson #

Deux options sont fournies pour construire la documentation en utilisant Meson. Positionnez-vous dans le répertoire build avant d'exécuter une de ces commandes, ou ajoutez -C build à la commande.

Pour construire uniquement la version HTML de la documentation : 

build$ ninja html

Pour une liste des autres cibles de documentation, voir Section 17.4.4.3. La sortie apparaît dans le sous-répertoire build/doc/src/sgml.
