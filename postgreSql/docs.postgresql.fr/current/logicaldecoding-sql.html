47.4. Interface SQL de décodage logique #

Voir Section 9.28.6 pour une documentation détaillée sur l'API de niveau SQL afin d'interagir avec le décodage logique.

La réplication synchrone (voir Section 26.2.8) est uniquement supportée sur des slots de réplication utilisés au travers de l'interface de réplication en flux. L'interface de fonction et autres interfaces additionnelles ne faisant pas partie du moteur, ils ne gèrent pas la réplication synchrone.
