Les sections qui suivent présentent les possibilités d'étendre le langage SQL de requêtage de PostgreSQL par l'ajout :

  • de fonctions (Section 36.3) ;

  • d'agrégats (Section 36.12) ;

  • de types de données (Section 36.13) ;

  • d'opérateurs (Section 36.14) ;

  • de classes d'opérateurs pour les index (Section 36.16).

  • d'extensions permettant de créer un paquetage d'objets qui disposent d'un point commun (voir Section 36.17)
