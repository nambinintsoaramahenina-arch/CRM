51.32. pg_namespace #

Le catalogue pg_namespace stocke les namespace. Un namespace est la structure sous-jacente aux schémas SQL : chaque namespace peut contenir un ensemble séparé de relations, types, etc. sans qu'il y ait de conflit de nommage.

Tableau 51.32. Colonnes de pg_namespace

Type

Description

oid oid

Identifiant de ligne

nspname name

Nom du namespace

nspowner oid (référence pg_authid.oid)

Propriétaire du namespace

nspacl aclitem[]

Droits d'accès ; voir Section 5.8 pour les détails.
